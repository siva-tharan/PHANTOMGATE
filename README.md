# PHANTOMGATE

PHANTOMGATE is an interactive cyber deception and intruder-trap
simulation built using Go, HTML, CSS and JavaScript.

## Features

- Simulated terminal
- Decoy file explorer
- Decoy login interaction
- Threat scoring
- Activity investigation
- Local JSONL event logging

## Technology

- Go
- HTML
- CSS
- JavaScript
- JSONL
